📖 ห้องเรียนสัญลักษณ์ Flowchart

ผังงาน (Flowchart) คือ การใช้รูปภาพสัญลักษณ์เพื่ออธิบายลำดับขั้นตอนการทำงาน

เริ่มต้น / จบ

1. จุดเริ่มต้น / สิ้นสุด (Terminal)

ใช้วางไว้ตำแหน่ง **แรกสุด** และ **สุดท้าย** ของผังงานเสมอ 🏁

กระบวนการ

2. การประมวลผล / ปฏิบัติงาน (Process)

ใช้บอกคำสั่งการทำงานหรือคำสั่งการปฏิบัติกิจกรรม ⚙️

เงื่อนไข ?

3. การตัดสินใจ / เงื่อนไข (Decision)

ใช้ตรวจสอบเงื่อนไข ซึ่งจะมีทางแยกออกเป็น **ใช่ (Yes)** หรือ **ไม่ใช่ (No)** ❓

รับ / แสดงผล

4. การรับข้อมูล / แสดงผล (Input/Output)

ใช้นำเข้าข้อมูลหรือสั่งให้แสดงผลลัพธ์ออกมา 📤

รูปแบบการทำงานหลัก 2 แบบ:

แบบ Sequence
1. การทำงานแบบลำดับ

ทำทีละขั้นตอนจากบนลงล่าง เรียงต่อกันตรงๆ เช่น การตื่นนอน -> แปรงฟัน -> อาบน้ำ

แบบ Condition
2. การทำงานแบบมีเงื่อนไข

มีการตัดสินใจ หากฝนตกให้ "พกร่ม" หากฝนไม่ตกให้ "เดินออกจากบ้านได้เลย"
